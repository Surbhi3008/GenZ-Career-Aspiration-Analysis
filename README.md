Objective

To understand what GenZ expects from their careers and provide data-driven insights that can help organizations improve hiring strategies, work culture, and compensation planning.

Tools & Technologies

Excel (Data Cleaning, Preprocessing)
SQL (Data Querying)
Power BI (Dashboard & Visualization)

Dataset

Survey dataset containing responses on salary expectations, team size preferences, and work priorities.

Key Analysis Performed

Data cleaning and transformation
Exploratory Data Analysis (EDA)
Trend and pattern identification
Dashboard creation

Key Insights

Majority of GenZ prefers balanced work-life culture
Mid-size teams are more preferred over very large or solo work
Salary expectations are concentrated in specific ranges
Work environment and flexibility are key decision factors
